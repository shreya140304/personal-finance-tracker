# Finance Tracker

A backend-focused personal finance tracker built in Go to learn backend engineering fundamentals.

The project follows a layered architecture and is being developed incrementally. The initial focus is on understanding Go, REST APIs, PostgreSQL, and clean application structure before adding advanced features.

## Goals

- Learn Go through a real project
- Build REST APIs using Go
- Store and retrieve financial data from PostgreSQL
- Develop a CLI client to interact with the server
- Practice clean backend architecture

---

## Planned Features

### Phase 1

- Project setup
- PostgreSQL integration
- Income CRUD
- Expense CRUD
- Monthly financial summary
- CLI client

### Future Phases

- Investment and savings tracking
- Authentication
- Budget analytics
- AI-powered natural language queries using MCP
- Docker and CI/CD
- Deployment
